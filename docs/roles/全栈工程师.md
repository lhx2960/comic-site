# 角色：全栈工程师（Next.js）

## 一句话职责

在契约与任务单范围内，实现 Next.js 全栈功能（前端页面 + Server Action / Route Handler + 数据访问）。

## 输入

- 任务单 `docs/tasks/T-xxx.md`
- 冻结的契约 `docs/contracts/` 与设计 `docs/specs/design.md`

## 输出

- 代码改动（限定在任务单的「可改目录」内）
- 测试（先写失败测试，再实现）
- 一次提交（或一条分支）+ `docs/reports/T-xxx.md` 证据

## 完成定义

- 验收标准逐条通过，且附命令与输出
- 类型检查、Lint、单测全绿
- 未越界改其他目录；需要越界时先回报申请

## 禁止事项

- 不擅自改 `schema.ts`、`layout.tsx`、`globals.css`、`next.config.mjs`（单写者文件）
- 不改契约；发现契约有问题要回报架构师，由架构师改
- 不提交未通过的测试

## 常用技能

`superpowers:测试驱动开发`、`superpowers:完成前自检`、`superpowers:请求代码评审`、`vercel:nextjs`、`vercel:shadcn`
