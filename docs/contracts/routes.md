# 契约：路由与 URL v1.0（冻结）

## 页面路由

| 路由 | 参数校验 | 正常 | 异常 |
| --- | --- | --- | --- |
| `/` | 无 | 200，首页即列表（Q1） | — |
| `/comics/[slug]` | 无（任何字符串都先当合法 slug 处理） | 200，详情页 | `getComic()` 返回 null → `notFound()`（404 页面） |
| `/comics/[slug]/[chapter]` | `chapter` 必须匹配 `^[1-9][0-9]*$`（正整数，无前导零） | 200，阅读页 | 格式不合法或 `getChapter()` 返回 null → `notFound()` |

## 查询参数（首页/列表）

| 键 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `q` | 任意字符串，前后空格忽略 | 无 | 标题/作者关键词 |
| `tag` | 标签 slug（小写字母数字连字符） | 无 | 单选；不存在的 tag 视为无筛选条件（不报错） |

约定：

- 两个参数都缺省时展示全部漫画（按 `order` 升序）。
- 参数顺序不影响结果；`?tag=scifi&q=星` 与 `?q=星&tag=scifi` 等价。
- 页面渲染时把**生效的筛选条件**显示出来，并提供「清除筛选」（F2-3、F2-4）。
- 无效/未知参数不做 400，按「无此条件」处理，保证链接永远可打开。

## Route Handler

`GET /api/comics/[slug]/chapters/[chapter]`

| 情况 | 状态码 | 响应体 |
| --- | --- | --- |
| 正常 | 200 | `ChapterDetail` JSON |
| `chapter` 格式不合法，或漫画/话不存在 | 404 | `{ "error": "not_found" }` |
| 其他未预期错误 | 500 | `{ "error": "internal_error" }` |

该接口**只服务于阅读页的下一话预取**，不对外承诺兼容性；客户端遇到 404 时显示「已是最后一话 / 这一话不存在」的降级 UI。

## 站点内链接约定

| 从哪里 | 到哪里 | 形式 |
| --- | --- | --- |
| 卡片 | 详情 | `/comics/{slug}` |
| 详情话列表条目 | 阅读页 | `/comics/{slug}/{chapter}` |
| 详情「开始阅读 / 继续阅读」 | 阅读页 | 同上（按 Q5 落点规则决定话与页） |
| 阅读页滚到底 | 下一话 | 地址栏替换为 `/comics/{slug}/{next}`（不新增历史记录） |
| 任何页面 | 首页 | 页头站点名 |
