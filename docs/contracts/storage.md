# 契约：本机阅读进度存储 v1.0（冻结）

## 存储位置与键

| 项 | 值 |
| --- | --- |
| 载体 | `window.localStorage`（只在本机、本浏览器） |
| key | `comicsite:progress:v1` |
| 值 | `ProgressMap` 的 JSON 字符串（结构见 `types.ts`） |
| 版本 | 键名带 `v1`；结构不兼容变更时换新键，旧键不迁移（本期不做迁移） |

## 写入规则

| 规则 | 说明 |
| --- | --- |
| 时机 | 阅读页滚动停止 500ms 后写入（防抖）；切页/卸载前不额外写 |
| 当前页口径 | **视口顶部起第一张可见页**（Q6）；边界情况见下方「当前页判定细则」 |
| 读到最后一话最后一页 | 该漫画记录 `finished: true` |
| 只增改进度 | 同一漫画只有一条记录，后写覆盖前写 |
| 站点不读别站数据 | key 前缀固定，不扫描其他键 |

**「当前页」判定细则（测试按此断言）**：取滚动容器的顶部坐标，找出第一张「底边仍在视口顶部之下」的页，即为当前页；若没有任何页满足，取最后一页。滚动停止后记录该页码，允许 ±1 页误差。

## 读取规则

| 场景 | 行为 |
| --- | --- |
| 客户端组件首次挂载 | 读取一次（`useEffect`），服务端不读（避免水合不一致） |
| 记录不存在或 JSON 解析失败 | 视为「无进度」，并**删除**损坏的键 |
| 记录指向不存在的话/页（数据变了） | 视为「无进度」，不进阅读页跳转 |
| 详情页 | 有记录 → 主按钮「继续阅读：第 x 话 第 y 页」+ 次要入口「从第 1 话重读」；无记录 → 主按钮「开始阅读」 |
| 详情页次要位置 | 提供「清除本机阅读记录」，点击后删除该漫画的记录并刷新入口状态 |

## 失败与边界

- 隐私模式或配额不足导致写入抛错：**吞掉异常**，不阻断阅读（页面不报错）。
- 不跨设备、不跨浏览器同步；清理浏览器数据等于清除进度（F6-4、F6-5）。
