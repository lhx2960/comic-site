## 背景

工程尚未创建，这是所有后续任务的地基。设计见 `design.md` §1–§5、§9、§11；契约见 `docs/contracts/types.ts`、`data-access.md`、`storage.md`。

## 要做的事

1. 初始化 Next.js（App Router）+ TypeScript（`strict`）+ Tailwind + ESLint + pnpm；`package.json` 提供 `dev` / `build` / `start` / `lint` / `type-check` / `test` / `e2e` 脚本
2. `scripts/generate-sample-data.mjs`：生成 3 部漫画（至少 1 个标题含字母，如「NEON 午夜快车」）、每部 5 话 × 每话 10 页 = 150 张 SVG 占位图（600×800，图面写页码）到 `public/comics/**`，并生成 `data/comics.ts`（字段按契约：slug/title/author/summary/tags/order/cover/chapters）；标签约 5 个，**每个标签至少命中 1 部**
3. `src/types/comic.ts` 与 `docs/contracts/types.ts` **逐字一致**
4. `src/lib/data/queries.ts` 实现 `listComics` / `listTags` / `getComic` / `getChapter`，语义严格按 `data-access.md`（关键词 trim + 大小写不敏感 + 片段包含、标签命中、交集、`order` 升序、空数组、`null`）
5. `src/lib/search-params.ts`：解析与构造 `?q=&tag=`（未知 tag 视为无筛选）
6. Vitest 单测覆盖第 4、5 条的所有语义分支
7. `src/app/globals.css`：把 `docs/specs/ui.md` 的设计令牌写进 Tailwind `@theme`（浅色站点 + 深色阅读两套）；ui.md 若尚未落盘，先用 `docs/design-preview/` 预览页里的令牌值并注明
8. 按硬规则 7 写中文机制注释
