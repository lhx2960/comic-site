## 背景

详情页负责「确认要不要看」与「从哪一话开始」；本机阅读进度的一切读写规则见 `docs/contracts/storage.md`（Q6 已定稿）。

## 要做的事

1. `progress.ts`：按 `storage.md` 实现 `readProgress(slug)` / `writeProgress(slug, record)` / `clearProgress(slug)` / `listProgress()`，key = `comicsite:progress:v1`；损坏数据删除、写入异常吞掉、只在浏览器端调用
2. `page.tsx`：服务端取 `getComic(slug)`；为 `null` 时 `notFound()`；渲染大封面 + 标题/作者/标签 + 简介 + 话列表
3. `ChapterList`：条目高度 ≥56px，显示话序号 + 话标题，本机进度所在话标记「读到此」
4. `ProgressCTA`（客户端）：挂载后读进度 → 有进度显示主按钮「继续阅读：第 x 话 第 y 页」+ 次要入口「从第 1 话重读」「清除本机阅读记录」；无进度显示「开始阅读」；读完显示「已读完」+ 从头再读
5. 单测：进度工具的读写/损坏/清除/多漫画隔离；`ProgressCTA` 三种状态渲染
6. 中文注释：重点解释「为什么只能在客户端挂载后读 localStorage（水合不一致）」
