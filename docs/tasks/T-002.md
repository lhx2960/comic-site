用户已确认：站点浅色、阅读页深色（D-006）；阅读模式为纵向长条滚动（D-004）；搜索含标题/作者关键词 + 标签筛选（D-005）；示例数据规模 3 部 × 5 话 × 10 页（D-003）。本任务把「长什么样」定下来，供**设计定稿闸门**给用户过目，并作为后续实现任务单的视觉依据。

## 第 3 次派发：移动端优先重设计（2026-09-25）

依据决策 **D-009**：以手机为主设计，桌面是增强。旧版预览（第 1 次派发产出）**作废**，允许覆盖 `docs/design-preview/` 下同名文件。

### 设计基准

| 宽度 | 定位 |
| --- | --- |
| 360px | 最小支持宽度（必须无横向滚动、无内容裁切） |
| 390px | **主设计基准**（截图与规格以此为准） |
| 430px | 大屏手机（如 iPhone Pro Max） |
| 1280px | 桌面增强（保持信息密度，不重新发明布局） |

### 首页（浏览/搜索/筛选）

1. 搜索框**常驻且吸顶**（滚动时仍可用），标签筛选条**横向滚动**不换行，滚动条隐藏。
2. 漫画卡片改为 **2 列网格**（封面 2:3 + 标题 + 作者 + 标签），宽度 ≤340px 时退化为单列横向卡（封面左、信息右）。
3. 保留「全部漫画 · 共 3 部」这类计数与分节标题；标签 chip 的可点区域 ≥44×44px。

### 详情页

1. 头部为「大封面 + 标题 / 作者 / 标签」垂直结构，手机上不再用小封面横排。
2. 主 CTA（开始阅读 / 继续阅读）在手机上**吸底固定**，含 `env(safe-area-inset-bottom)` 留白；次入口（从第 1 话重读、清除本机记录）收起为文字按钮。
3. 面包屑在手机上简化为「返回 + 当前漫画名」；话列表条目高度 ≥56px，「读到此」标记保留。

### 阅读页（本期核心）

1. 图片 **100% 宽、左右零留白**（全出血），页与页之间 0 间距（用 1px 暗色分隔线）。
2. 顶部信息条（返回 + 漫画名 + 话序号）**向下滚动时隐藏、向上滚动或点按画面时显示**（沉浸阅读）。
3. 底部固定**细进度条** + 「第 x 话 · 第 y 页」文字；进度条不遮挡图片内容。
4. 「接下一话」区块整宽、可点区域 ≥56px；加载中显示骨架。
5. `env(safe-area-inset-bottom)` 处理下巴；`overscroll-behavior-y: contain` 防止滚动穿透与误触下拉刷新。

### 通用硬指标

- 输入框字号 ≥16px（避免 iOS 聚焦自动放大）；可点区域 ≥44×44px，相邻触控目标间距 ≥8px。
- 正文对比度达 WCAG AA；Tab 焦点可见；横向滚动容器**不得**让页面出现横向滚动条。
- 三种状态（空 / 加载中 / 错误）在两种宽度下都要给出样张；阅读页另有「单张图片失败」态。
