# T-002 UI 设计规格与静态预览（范围 B）

| 字段 | 内容 |

| 承接角色 | UI 设计（一次性子代理任务） |

## 背景

用户已确认：站点浅色、阅读页深色（D-006）；阅读模式为纵向长条滚动（D-004）；搜索含标题/作者关键词 + 标签筛选（D-005）；示例数据规模 3 部 × 5 话 × 10 页（D-003）。本任务把「长什么样」定下来，供**设计定稿闸门**给用户过目，并作为后续实现任务单的视觉依据。

工程尚未创建（还没有 `package.json`），所以预览必须是**不依赖构建工具的独立 HTML**。

## 要做的事

1. 读 `AGENTS.md`、`docs/specs/prd.md`、`docs/specs/决策记录.md`
2. 在 `docs/specs/ui.md` 定义**设计令牌**：浅色站点色板与深色阅读色板（都给十六进制值）、字号阶梯、行高、间距刻度、圆角、阴影、边框、图片占位规则
3. 写 4 个页面的布局规格（手机 390px / 桌面 1280px 两种宽度）：**首页**、**列表 + 搜索 + 标签筛选**、**漫画详情（含话列表）**、**阅读页（长条滚动 + 进度 + 接下一话）**；每页列出组件清单（组件名、状态、交互、中文文案示例）
4. 每页补「空状态 / 加载中 / 错误」三种状态的视觉说明
5. 在 `docs/design-preview/` 写独立 HTML 预览（每个页面一个文件，内联 CSS，系统字体栈，不引外部 CDN/字体/图片），并用无头浏览器把每个页面截成 PNG 存到同目录
6. `docs/specs/ui.md` 里引用这些截图（相对路径）
7. 按 `docs/reports/模板-任务回报.md` 落盘 `docs/reports/T-002.md`

## 验收标准

- [ ] `docs/specs/ui.md` 含完整设计令牌：浅色与深色两套色板（十六进制）、字号/行高/间距/圆角/阴影刻度
- [ ] 4 个页面都有手机与桌面两种宽度的布局规格，并列出组件清单（含状态与交互）
- [ ] 每页都有空状态、加载中、错误状态的视觉说明
- [ ] 阅读页规格体现：深色背景、图片宽度约束与占位比例（避免滚动布局跳动）、阅读进度提示、滚到底接下一话的入口
- [ ] 每页三种状态下都有中文文案示例（不是 lorem ipsum）
- [ ] `docs/design-preview/*.html` 双击即可打开，不依赖构建、不引外部资源
- [ ] 每个页面都有对应 PNG 截图，且被 `ui.md` 引用（相对路径可显示）
- [ ] 可点区域不小于 44×44px、正文对比度达 WCAG AA、键盘可达（焦点可见），并在文档中说明
- [ ] `docs/reports/T-002.md` 有证据（命令与输出）、改动文件清单、验收标准逐条核对

## 约束

- 只写上述三个位置，不改 `AGENTS.md`、`docs/specs/决策记录.md`、`docs/specs/prd.md`、`docs/tasks/`、`docs/contracts/`
- 不写实现代码（不建工程、不装依赖、不写组件）；预览 HTML 是**设计稿**，允许与最终实现结构不同
- 不引入任何外部网络资源（CDN、字体、图片）；占位图用纯 CSS 色块/渐变表示
- 截图用现成无头浏览器工具（见技能 `浏览器自动化`），不要往仓库里装 node_modules

## 回报要求

状态（DONE / DONE_WITH_CONCERNS / NEEDS_CONTEXT / BLOCKED）+ 证据（命令与输出）+ 改了哪些文件 + 验收标准逐条核对 + 遗留问题与建议。
