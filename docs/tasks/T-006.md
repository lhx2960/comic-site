## 背景

阅读页是本项目最核心、也最复杂的一页（D-004、D-009 移动优先）；本任务只做「本话之内」的阅读体验，**接下一话留给 T-007**。视觉规格见 `docs/specs/ui.md` 阅读页章节。

## 要做的事

1. `page.tsx`（服务端）：校验 `chapter` 为正整数（`^[1-9][0-9]*$`），取 `getChapter()`；`null` → `notFound()`；渲染标题区与 `ReaderStrip`
2. `ReaderStrip`（客户端）：纵向长条滚动；图片 **100% 宽、左右零留白**；每页用固定 3:4 比例容器包住 `next/image`，**加载前后不发生位移**（F5-12）
3. 懒加载（F5-10）：`IntersectionObserver` 或 `loading="lazy"`，首屏之外的页不发起请求
4. `RetryableImage`：单张图加载失败时显示「图片加载失败 + 重试」，重试只重新请求该图，不影响其它页（Q12）
5. 沉浸式顶部条：向下滚动隐藏、向上滚动或点按画面显示（含返回详情入口与「第 x 话」标题）
6. `ReaderProgressBar`：底部固定细进度条 + 「第 x 话 · 第 y 页」，不遮挡画面内容
7. 进度写入：滚动停止 500ms 后写入当前页（口径 = 视口顶部往下第一张可见页，见 `storage.md`）
8. 单测：进度条百分比计算、失败重试分支、`RetryableImage` 错误态渲染
9. 中文注释：重点解释「为什么必须给图片固定尺寸」「IntersectionObserver 在 Next.js 里为什么放客户端」
