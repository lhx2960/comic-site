## 背景

用户已确认项目范围 = **B（MVP 带轻后端）**，决策见 `docs/specs/决策记录.md` 的 D-001 ～ D-005。本节目的：把范围变成「可被测试验证」的需求，作为架构设计（`docs/specs/design.md`）与后续任务单的唯一需求依据。

已定决策摘要：

- D-001 范围 B：浏览、搜索、漫画详情、在线阅读页；**账号、收藏、评论、付费明确不做**
- D-002 用户正在学 Next.js，代码要有逐步中文注释（本 PRD 只记录该偏好，不写技术方案）

- D-004 阅读模式 = 纵向长条滚动，滚到底接下一话；本地记住阅读进度
- D-005 搜索 = 标题 + 作者关键词 + 标签筛选，筛选状态写进 URL

## 验收标准

- [ ] `docs/specs/prd.md` 覆盖：首页浏览、漫画列表 + 标签筛选、搜索（标题/作者）、漫画详情（含话列表）、阅读页（长条滚动、接下一话、阅读进度记忆），以及全局的空状态/错误状态要求
