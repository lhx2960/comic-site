## 1. 一句话目标

让没有账号的访客在手机或桌面上完成闭环：**看到站点有什么漫画 → 用标签或关键词找到想看的 → 打开详情选一话 → 纵向连续读完，并能在下次回来接着读**。

## 2. 目标用户与核心场景

| 用户类型 | 特征 | 核心场景 | 对应功能 |
| --- | --- | --- | --- |
| 「逛」的访客 | 第一次来，不知道看什么 | 打开站点第一屏就看到 3 部漫画卡片与标签；点一个感兴趣的标签缩小范围 | F1、F2 |
| 「找」的访客 | 记得漫画名或作者名 | 在搜索框输入标题或作者关键词，拿到匹配结果 | F3 |
| 「决定看哪一话」的访客 | 已选中一部漫画 | 打开详情页看标题、作者、标签、简介与 5 话列表，从第 1 话或某一话开始 | F4 |
| 「读」的读者 | 正在读某一话 | 纵向长条滚动读一话，滚到底继续下一话，中途不需要反复点击 | F5 |
| 「中断后回来」的读者 | 上次看到一半 | 下次打开站点仍能看到自己的进度并接着读 | F6（P1） |

**成功判据（可验证）**：上述 5 个场景在示例数据（3 部 × 5 话 × 10 页，D-003）上都能走通，全程不需要账号。

## 3. 范围总览

**优先级定义**

- **P0**：缺少则 MVP 不成立，验收必须通过。
- **P1**：本期计划做；若与 P0 冲突，可在任务单中记录后延后。

| 功能 | 名称 | 优先级 | 依据决策 |
| --- | --- | --- | --- |
| F1 | 首页浏览 | P0 | D-001、D-003 |
| F2 | 漫画列表与标签筛选 | P0 | D-001、D-005 |
| F3 | 搜索（标题 + 作者） | P0 | D-001、D-005 |
| F4 | 漫画详情（含话列表；继续阅读与清除记录入口为 P1） | P0 | D-001、D-003 |
| F5 | 阅读页（长条滚动 + 接下一话；F5-10 ～ F5-12 为 P1 配套） | P0 | D-001、D-004 |
| F6 | 阅读进度记忆 | P1 | D-004（配套项） |
| G1 ～ G5、G7 ～ G10 | 全局要求（内容规模、空状态、错误状态、视口、导航、一致性、文案、视觉基调） | P0 | D-001、D-003、D-006 |
| G6 | 键盘可达性 | P1 | 架构师确认（可访问性最低线） |

**关于 D-002（学习导向注释）**：这是开发约定，不是产品需求。本 PRD 只登记它存在于 `AGENTS.md` 硬规则第 7 条，具体落地由设计文档与各任务单的「交付格式」承接。

**验收执行前提**：测试一律使用示例数据（3 部漫画 × 每部 5 话 × 每话 10 页占位图）；下文中「标签 A」「第 3 话」等示例值，均以示例数据的具体内容核对；视觉类判定（G10）以 `docs/specs/ui.md` 的设计令牌为准。

## 4. 功能需求与验收标准

写法约定：每条 AC 给出 **输入/操作** 与 **预期结果**；带 «Q-x» 的条目表示其取值来自 §8 记录的 Q-x 定论，便于复核时逐条追溯（定论原文见 `docs/specs/架构师答复-Q1-Q14.md`）。

### F1 首页浏览（P0，依据 D-001、D-003）

**目标**：访客打开站点第一屏就能看到全部可看内容与「找漫画」入口。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F1-1 | 打开站点首页 | 出现 3 张漫画卡片；每张卡片显示封面图、标题、作者、至少 1 个标签；卡片上不出现阅读进度标记 «Q14» |
| F1-2 | 点击任意一张漫画卡片 | 进入该漫画的详情页；详情页显示的标题与作者与卡片一致 |
| F1-3 | 查看首页 | 存在搜索输入框，可输入文字并提交 |
| F1-4 | 查看首页标签区 | 列出的标签 = 示例数据中出现过的全部去重标签，且每个标签至少命中 1 部漫画（数量与名称按数据核对） «Q2» |
| F1-5 | 点击首页的「标签 A」 | 展示的漫画只剩带「标签 A」的那些；页面上能看到当前生效的筛选条件；首页本身就是列表视图，不发生页面跳转 «Q1» |
| F1-6 | 查看首页页头与首屏文案 | 页头显示站点名「漫画站」；首页显示副标题「示例数据练手的漫画阅读站」 «Q9» |

### F2 漫画列表与标签筛选（P0，依据 D-001、D-005）

**目标**：用户可以按标签缩小范围，且筛完的状态在刷新、分享后不丢。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F2-1 | 打开站点首页（首页即列表视图） | 按数据文件给定顺序列出全部 3 部漫画 «Q1» «Q7»；每部显示封面、标题、作者、标签，且不显示阅读进度标记 «Q14» |
| F2-2 | 点击列表中的漫画卡片 | 进入该漫画的详情页 |
| F2-3 | 点选「标签 A」（命中数量按示例数据核对） | 列表只保留带「标签 A」的漫画（数量与名称按数据核对）；页面显示当前筛选条件（标签名）与「清除筛选」入口 «Q2» |
| F2-4 | 点击「清除筛选」 | 恢复显示全部 3 部；筛选条件标识消失 |
| F2-5 | 选中「标签 A」时按浏览器刷新 | 刷新后的筛选结果与刷新前一致，仍只显示带「标签 A」的漫画（D-005：刷新不丢状态） |
| F2-6 | 选中「标签 A」时复制页面地址，在另一个浏览器窗口打开 | 打开的页面显示同样的漫画集合与同样的筛选状态（D-005：分享不丢状态） |
| F2-7 | 输入关键词「K」并选中「标签 A」后提交 | 结果 = 「标题或作者包含 K」且「带标签 A」的漫画（两个条件同时生效，取交集） |
| F2-8 | 已选中「标签 A」时再次点击该标签 | 取消该标签筛选，恢复显示全部 3 部 «Q3» |
| F2-9 | 选中一个关键词与标签的交集为空（如无匹配关键词 + 任意标签） | 显示空状态提示，按 G2 执行 «Q2» |

### F3 搜索：标题与作者（P0，依据 D-001、D-005）

**目标**：记得名字或作者的人能一次命中，记不全也能用片段搜到。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F3-1 | 搜索框输入某部漫画的完整标题并提交 | 结果列表包含该漫画；同一部漫画在结果中只出现一次 |
| F3-2 | 输入某作者的姓名并提交 | 结果包含示例数据中该作者的全部作品（数量按数据核对） |
| F3-3 | 输入标题的中间片段（不含开头字符）并提交 | 结果包含标题含该片段的漫画（按「包含」匹配，不要求从开头匹配，D-005） |
| F3-4 | 用全大写与全小写分别输入同一个含字母的标题 | 两次结果相同（大小写不敏感，D-005）；示例数据需至少含 1 个含字母的标题 «Q11» |
| F3-5 | 输入无任何匹配的关键词（如「zzzz」）并提交 | 显示空状态提示，按 G2 执行；输入框中保留该关键词 |
| F3-6 | 清空关键词并提交 | 回到无关键词状态：当前有标签筛选则只显示该标签的结果，否则显示全部 3 部 |
| F3-7 | 输入首尾带空格的关键词（如「空格 + 星海 + 空格」）并提交 | 结果与不带首尾空格的同一关键词完全一致 |
| F3-8 | 输入只出现在某个标签文字里、但没有出现在任何标题/作者中的词 | 默认不匹配（结果为 0 条，按 G2 显示） «Q4» |

### F4 漫画详情（P0，依据 D-001、D-003）

**目标**：用户在这里确认「这部是不是我要看的」并选择从哪一话开始。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F4-1 | 打开某部漫画的详情页 | 显示：标题、作者、全部标签、简介文本（示例数据提供的字段）、话列表；不显示连载状态、阅读量等元信息 «Q8» |
| F4-2 | 查看话列表 | 共 5 条；按话序号 1 → 5 升序排列；每条只显示话序号与话标题，不显示页数 «Q8» |
| F4-3 | 该话无本地阅读进度时，点击第 3 话 | 进入第 3 话阅读页，从该话第 1 页开始 «Q5» |
| F4-4 | 该漫画无本地阅读进度时，查看详情页主按钮 | 主按钮文案为「开始阅读」；点击后进入第 1 话第 1 页 «Q5» |
| F4-5 | 打开数据中不存在的漫画（把地址里的编号改成数据里没有的值） | 显示「这部漫画不存在」提示 + 返回首页或列表的入口；不出现错误堆栈、不出现空白页 |
| F4-6 | 本机已有该漫画的阅读进度时打开详情页（P1） | 主按钮文案变为「继续阅读：第 x 话 第 y 页」（x、y 等于记录值）；点击后进入该话该页（依赖 F6） «Q5» «Q6» «Q10» |
| F4-7 | 本机已有该漫画的阅读进度时，点击次要入口「从第 1 话重读」（P1） | 进入第 1 话第 1 页；此时返回详情页，主按钮仍显示点击前记录的「第 x 话 第 y 页」 «Q5» «Q6» |
| F4-8 | 本机已有该漫画的阅读进度时，点击详情页次要位置的「清除本机阅读记录」（P1） | 进度入口消失、主按钮回到「开始阅读」；再进入阅读页从第 1 页开始（依赖 F6） «Q6» |
| F4-9 | 打开任意漫画详情页 | 页面可见站点名「漫画站」，并存在回到首页（列表视图）的入口（按 G7 执行） «Q9» |

### F5 阅读页：纵向长条滚动 + 接下一话（P0，依据 D-001、D-004）

**目标**：一话读到底不断档，读完自然接下一话，全程不需要反复点击。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F5-1 | 进入任意一话的阅读页 | 该话 10 页图片按页序从上到下纵向排列；不出现缺页、重复页或顺序错乱 |
| F5-2 | 查看阅读页标题区 | 显示漫画标题与当前话序号（如「第 3 话」） |
| F5-3 | 在 360px 与 1440px 两种视口下横向查看阅读页 | 页面不出现横向滚动条；每页图片宽度一致、单页完整落在视口宽度内 |
| F5-4 | 从第 3 话顶部连续向下滚动到底部 | 底部出现「下一话（第 4 话）」区块；继续向下即呈现第 4 话内容，同时阅读页标题区与地址栏中的话序号更新为第 4 话（滚到底接下一话，D-004） «Q5» |
| F5-5 | 在第 5 话（最后一话）滚动到底部 | 显示「已是最后一话」提示 + 返回详情与回到顶部的入口 «Q5» |
| F5-6 | 已滚动到第 4 话中段时向上滚回 | 仍能看到第 3 话末尾的内容，阅读顺序保持 3 → 4 连续 |
| F5-7 | 第 5 话无本地进度时，从详情页点击第 5 话进入阅读 | 从第 5 话第 1 页开始；该话之后不再接续内容，底部按 F5-5 收尾 «Q5» |
| F5-8 | 该话无本地进度时，直接把地址中的话序号改成第 2 话并打开 | 从第 2 话第 1 页开始，标题区显示第 2 话 «Q5» |
| F5-9 | 打开数据中不存在的话（把地址中的话序号改成数据里没有的值） | 显示「这一话不存在」提示 + 返回该漫画详情的入口；不出现错误堆栈 |
| F5-10 | 进入任意一话阅读页且不滚动（P1） | 只有首屏附近的页面图片发起加载请求；首屏之外、尚未滚动到的页面图片不发起请求，滚动到该页附近时才发起（D-004 配套：图片懒加载） |
| F5-11 | 在第 3 话读到接近底部（剩余不足一屏）时查看网络请求（P1） | 第 4 话第 1 页的图片请求已经发出；继续滚动进入第 4 话时该图无需重新加载即可显示（D-004 配套：预加载下一话） |
| F5-12 | 从进入阅读页到 10 页图片全部加载完成，记录当前可见内容的位置（P1） | 图片从「加载中」变为「已加载」的过程中，已渲染内容不发生上下位移；360px 与 1440px 两种视口各验证一次（D-004 配套：滚动过程无布局跳动） |

### F6 阅读进度记忆（P1，依据 D-004 配套项）

**目标**：看一半离开的人，下次回来能接着读；不需要账号，也不跨设备同步。

| AC | 输入 / 操作 | 预期结果 |
| --- | --- | --- |
| F6-1 | 阅读第 3 话并滚动到第 6 页（以「视口顶部往下第一张可见页」为准），停留超过 0.5 秒后关闭浏览器 | 关闭过程中无报错；下次打开站点时，「继续阅读」信息仍指向该漫画的第 3 话 «Q6» |
| F6-2 | 重新进入该漫画第 3 话 | 从第 6 页位置开始，不回到第 1 页；判定口径同 F6-1（视口顶部往下第一张可见页），断言允许 ±1 页（记录值为第 5 / 6 / 7 页均判通过） «Q6» |
| F6-3 | 打开该漫画详情页 | 主按钮显示「继续阅读：第 3 话 第 6 页」，与记录值一致 «Q6» «Q10» |
| F6-4 | 换另一个浏览器（或另一台设备）打开站点 | 不出现「继续阅读」信息；进入阅读页从第 1 页开始（进度只在本机，D-004） |
| F6-5 | 清理浏览器本地数据后再打开站点 | 不出现「继续阅读」信息；阅读从第 1 页开始 |
| F6-6 | 检查记录粒度 | 进度按「漫画 + 话 + 页序号」记录；滚到第 6 页时记录值可被验证为「第 3 话 第 6 页」 «Q6» |
| F6-7 | 读到第 5 话最后一页 | 该漫画进度标记为「已读完」；详情页显示「已读完」与从头再读的入口 «Q6» |

**清除入口说明**：手动清除本机阅读记录的入口在详情页次要位置（不在阅读页），验收见 F4-8。

## 5. 全局要求

| 编号 | 要求 | 可测试的判定方式 |
| --- | --- | --- |
| G1 | 内容规模（D-003） | 站点共 3 部漫画，每部 5 话，每话 10 页占位图；每部有标题、作者、标签、简介 |
| G2 | 空状态 | 任何「搜索或筛选后 0 条结果」的场景，页面显示明确提示（如「没有找到匹配的漫画」）+ 清除关键词或清除筛选的入口；不出现空白页、错误页 «Q2» |
| G3 | 内容不存在 | 访问数据中不存在的漫画/话/页时，显示「内容不存在」类提示 + 返回首页或返回上级页面的入口；不出现错误堆栈、不出现白屏 |
| G4 | 加载失败与重试 | 前提：失败可被测试可控地制造（数据请求失败用请求拦截或离线模拟，图片失败用不可用的图片地址），恢复后再点「重试」。判定：失败时显示失败提示与「重试」入口，不出现空白页与错误堆栈；恢复后点击重试内容成功加载；单张图失败只影响该张图，该页其余内容与后续页仍可读 «Q12» |
| G5 | 视口适配与浏览器矩阵 | 视口从 360px 起：在 360×640 与 1440×900 下无横向滚动条；卡片、标签、搜索框、话列表条目均可点击；阅读页图片完整可见。浏览器：最近两个大版本的 Chrome / Edge / Safari（含 iOS Safari）各跑一次关键路径；不覆盖 IE 与更旧版本 «Q13» |
| G6 | 键盘可达性（P1，依据：架构师确认的可访问性最低线） | 仅用 Tab/Enter 可依次到达搜索框、标签、漫画卡片、话列表条目并进入对应页面；页面图片有文字替代说明 |
| G7 | 导航与站点标识 | 首页与详情页页头可见站点名「漫画站」；阅读页提供返回详情入口，站点名经详情页一跳可达（依据 D-018，阅读页顶栏以 `docs/specs/ui.md` §5.4 为准）；除首页外的每个页面都有回到首页的入口；详情页可回到首页（列表视图即首页），阅读页可回到详情 «Q9» |
| G8 | 数据一致性 | 同一部漫画在首页、列表、搜索结果、详情页的标题/作者/标签完全一致；话与页在任何入口进入时顺序稳定（1 → 5、1 → 10） |
| G9 | 文案语言 | 界面文案为简体中文；每个空状态与错误状态都给出下一步动作（清除条件 / 重试 / 返回） |
| G10 | 视觉基调（D-006） | 站点页面（首页、详情页）以浅色底渲染，阅读页以深色底渲染；具体色值取自 `docs/specs/ui.md` 的设计令牌（ui.md 定稿前以 `docs/design-preview/` 预览页的令牌值取样比对）；阅读页内不出现站点浅色底的区块 |

## 7. 术语

| 术语 | 含义 |
| --- | --- |
| 漫画（作品） | 站点内容的最小单元之一，含标题、作者、标签、简介、以及若干「话」 |
| 话（章节） | 漫画下的有序单元；示例数据中每部 5 话，序号 1 → 5 |
| 页 | 一话下的有序单元；示例数据中每话 10 页，序号 1 → 10，对应一张图片 |
| 标签 | 题材标记，可被多部漫画共用（多对多），既是筛选入口也是搜索结果的辅助信息 |
| 阅读进度 | 本机记录的「漫画 + 话 + 页序号」，用于「继续阅读」 |
| 空状态 | 请求成功但没有匹配内容时的页面状态（0 条结果） |
| 错误状态 | 访问不存在的内容、或内容加载失败时的页面状态 |

## 8. Q1 ～ Q14 定论与落点（来源：`docs/specs/架构师答复-Q1-Q14.md`）

v1.1 已把 Q1 ～ Q14 的定论全部落进正文；下表用于复核时逐条追溯。「«Q-x»」标记的含义是「该条 AC 的取值来自 Q-x 的定论」。

| 编号 | 定论 | 落点 AC |
| --- | --- | --- |
| Q1 | 首页与列表是同一个视图，不另设独立列表页 | F1-5、F2-1、G7 |
| Q2 | 保证每个标签至少命中 1 部漫画（标签由数据生成并校验） | F1-4、F2-3、F2-9、G2 |
| Q3 | 标签单选；再次点击同一标签 = 取消；不设「全部」项 | F2-3、F2-4、F2-8 |
| Q4 | 只匹配标题与作者，不匹配标签文本与简介 | F3-8 |
| Q5 | 滚到底出现「下一话」区块并向下接续，同步更新标题区与地址栏；最后一话显示「已是最后一话」+ 返回详情 / 回到顶部；进入某话时「该话有本地进度则从记录页继续，否则从第 1 页」；详情页主按钮随进度变化，另给「从第 1 话重读」 | F4-3、F4-4、F4-6、F4-7、F5-4、F5-5、F5-7、F5-8 |
| Q6 | 进度粒度 = 漫画 + 话 + 页；滚动停止（防抖 500ms）后记录；当前页 = 视口顶部往下第一张可见页；读完最后一话标记「已读完」；详情页次要位置提供「清除本机阅读记录」 | F4-6、F4-7、F4-8、F6-1、F6-2、F6-3、F6-6、F6-7 |
| Q7 | 列表按数据文件给定的顺序展示，本期不做热度 / 更新时间排序 | F2-1 |
| Q8 | 详情页不展示连载状态、阅读量；话列表只显示话序号 + 话标题，不显示页数 | F4-1、F4-2 |
| Q9 | 站点名「漫画站」，首页副标题「示例数据练手的漫画阅读站」 | F1-6、F4-9、G7 |
| Q10 | 详情页显示「继续阅读：第 x 话 第 y 页」 | F4-6、F6-3 |
| Q11 | 示例数据至少含 1 个带字母的标题 | F3-4 |

| Q13 | 视口从 360px 起；浏览器 = 最近两个大版本的 Chrome / Edge / Safari（含 iOS Safari） | G5 |
| Q14 | 首页/列表卡片不显示阅读进度标记，进度只在详情页出现 | F1-1、F2-1 |
