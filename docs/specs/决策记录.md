## D-004 阅读模式 = 长条滚动

| 字段 | 内容 |
| --- | --- |
| 日期 | 2026-09-25 |
| 决策人 | 用户 |
| 状态 | 已定稿 |

- **决策**：阅读页采用**纵向长条滚动**，一话的页面顺序排下来，滚到底部接下一话。
- **配套（架构师拟定，设计闸门时确认）**：手机优先、桌面可用；图片懒加载 + 预加载下一话；本地记住阅读进度（存浏览器，不需要账号）。
- **理由**：手机端最自然，实现路径清楚，能覆盖 `next/image` 优化、懒加载、滚动进度、状态持久化等真实问题。
- **影响**：阅读页是本期核心页面；数据模型里「话 → 有序页列表」必须稳定有序；图片尺寸与宽高比需入库，避免滚动时布局跳动。
